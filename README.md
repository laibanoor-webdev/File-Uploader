# File Uploader

A simple and user-friendly File Uploader built using **HTML, CSS, and JavaScript**.

## Features

* Drag & Drop image upload
* Browse File option
* Supports JPG, PNG, and GIF images
* Image preview
* Displays file name and file size
* Upload progress bar
* Remove image option
* Invalid file type validation

## Technologies Used

* HTML
* CSS
* JavaScript
